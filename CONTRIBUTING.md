# Karibu Ku-contribute kwenye JSON.org (Kenyan Edition) 🇰🇪🤝

Karibu sana kwenye mradi wa wazi (Open Source) wa kutafsiri na kudumisha rasmi spec ya **JSON.org** kwa lugha ya kawaida ya Kenya bila deep translation.

---

## 📌 Kanuni Kuu
* Maneno ya kusanifu data na code kama `object`, `array`, `string`, `number`, `boolean`, `null`, `whitespace`, `parse`, `generate` yanabaki vile yalivyo.
* Logic ya spec inaelezwa kwa lugha ya kawaida bila maneno magumu ya kamusi.
* Usahihi wa kisayansi wa **ECMA-404 Standard** lazima uzingatiwe 100%.

Asante kwa kuunga mkono jamii ya wazi ya tech Kenya! 🚀
